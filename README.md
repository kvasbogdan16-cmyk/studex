# Studex

Лендинг платформи, де студенти шукають першу роботу, підробіток або волонтерство.

**Сайт:** https://studex-ochre.vercel.app
**Адмін-панель:** https://studex-ochre.vercel.app/admin

## Як це працює

- **Форма заявки** (`index.html`, `script.js`) надсилає дані на `/api/lead`.
- **`api/lead.js`** (функція Vercel) зберігає заявку в Supabase і надсилає сповіщення в Telegram.
- **Адмін-панель** (`admin.html`, `admin.js`) після входу показує заявки (нові зверху), дає змінити статус і відфільтрувати за статусом. Налаштування Supabase бере з `/api/config`.
- **База даних**: таблиця `leads` зі статусами «нова», «в роботі», «закрита» (`supabase.sql`) і доступ лише для адмінів (`supabase-admin.sql`).
- **CRM** (`supabase-crm.sql`, запускати третім): етапи воронки, джерело заявки («Сайт» / «Вручну») та історія переходів між етапами, яку записує сама база.
- **Розпізнавання візиток** (`supabase-scan.sql`, запускати четвертим; `api/scan.js`): фото або PDF візитки йде в Claude API, адмін перевіряє поля, клієнт потрапляє у воронку з джерелом «Візитка», оригінал зберігається в закритому сховищі Supabase. Потрібна змінна `ANTHROPIC_API_KEY` у Vercel.
- **Telegram Mini App** (`supabase-telegram.sql`, запускати п'ятим; `tg.html`, `api/tg-*.js`): кнопка «Вакансії» в боті відкриває каталог, заявка потрапляє в CRM з джерелом «Telegram» і ім'ям з Telegram, у «Моїх заявках» видно етап. Сервер перевіряє підпис Telegram (initData) ключем бота і звертається до бази через секрет `TG_SERVER_SECRET` (у базі зберігається лише його SHA-256). Кнопку меню бота налаштовує `POST /api/tg-setup`.
- **Картинки для вакансій** (`supabase-images.sql`, запускати шостим; `api/generate.js`): в адмінці розділ «Картинки» — опис → GPT Image (`gpt-image-2.5-flare`) на сервері → картинка в закритому сховищі Supabase й історії генерацій. Ліміт 5 на день на адміна (перевіряє база), невдалі спроби не рахуються. Потрібна змінна `OPENAI_API_KEY` у Vercel.
- **Чат відмов** (`supabase-refusals.sql`, запускати сьомим; `api/refusals-*.js`): окремий бот у Telegram-групі. Менеджери пишуть відмову за шаблоном (`Місто:`, `Причина:`, за бажанням `Ім'я:` і `Коментар:`; місто можна вказати хештегом `#Львів`), бот зберігає її й ставить 👍. Редагування повідомлення оновлює відмову, `/undo` у відповідь на неї прибирає її зі звітів, `/help` показує шаблон. 1-го числа о 07:00 UTC Vercel Cron запускає `/api/refusals-report`, і в чат приходять два звіти за минулий місяць (межі місяця за київським часом). Загальний звіт: кількість і динаміка до попереднього місяця, розбивка по містах і топ причин. Детальний по Львову: причини, тижні, хто вносив і список усіх відмов із посиланнями на повідомлення.

### Як підключити чат відмов

1. У @BotFather створи нового бота, а його токен збережи у Vercel як `REFUSALS_BOT_TOKEN`.
2. Додай бота в групу й зроби його адміном. Без цього він бачить лише команди, а не звичайні повідомлення. Інший варіант: вимкни Group Privacy в @BotFather і додай бота заново.
3. Запусти `supabase-refusals.sql` у Supabase.
4. Задай у Vercel `CRON_SECRET` (будь-який довгий випадковий рядок) і задеплой.
5. Підключи вебхук: `curl -X POST https://studex-ochre.vercel.app/api/refusals-setup -H "X-Setup-Secret: <TG_SERVER_SECRET>"`.
6. Напиши `/help` у групі. Бот покаже ID чату: збережи його у Vercel як `REFUSALS_CHAT_ID` і задеплой ще раз. Якщо групу колись перетворять на супергрупу, ID зміниться, і його треба буде оновити.
7. Щоб перевірити звіт, не чекаючи 1-го числа: `curl "https://studex-ochre.vercel.app/api/refusals-report?month=2026-11" -H "Authorization: Bearer <CRON_SECRET>"`.

## Ключі

У коді немає жодного ключа чи токена. Усі вони зберігаються у Vercel → Settings → Environment Variables:

| Змінна | Що це |
|---|---|
| `SUPABASE_URL` | адреса проєкту Supabase |
| `SUPABASE_PUBLISHABLE_KEY` | publishable-ключ Supabase |
| `TELEGRAM_BOT_TOKEN` | токен бота від @BotFather |
| `TELEGRAM_CHAT_ID` | чат, куди приходять сповіщення |
| `REFUSALS_BOT_TOKEN` | токен бота чату відмов |
| `REFUSALS_CHAT_ID` | ID групи відмов (бот покаже його на `/help`) |
| `CRON_SECRET` | секрет, з яким Vercel Cron запускає щомісячний звіт |

Шаблон є в `.env.example`.
